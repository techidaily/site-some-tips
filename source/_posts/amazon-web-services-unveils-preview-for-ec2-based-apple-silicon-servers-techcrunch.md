## Amazon Web Services Unveils Preview for EC2-Based Apple Silicon Servers | TechCrunch

Amazon Web Services on Thursday [announced](https://buy.geni.us/Proxy.ashx?TSID=368250&GR%5FURL=https%3A%2F%2Faws.amazon.com%2Fblogs%2Faws%2Fuse-amazon-ec2-m1-mac-instances-to-build-test-macos-ios-ipados-tvos-and-watchos-apps%2F%3Ftag%3Dzd-buy-button-20%26ascsubtag%3D%5F%5FCOM%5FCLICK%5FID%5F%5F%7Ca447c80a-2c07-4570-9cb0-2dbd8cedaec4%7Cdtp&dtb=1)that [EC2 M1 Mac instances](https://buy.geni.us/Proxy.ashx?TSID=368250&GR%5FURL=https%3A%2F%2Faws.amazon.com%2Fec2%2Finstance-types%2Fmac%2F%3Ftag%3Dzd-buy-button-20%26ascsubtag%3D%5F%5FCOM%5FCLICK%5FID%5F%5F%7Ca447c80a-2c07-4570-9cb0-2dbd8cedaec4%7Cdtp&dtb=1) are now available in preview. The new instances let developers access machines built around Apple's custom-built M1 System on Chip (SoC), so they can re-architect their apps to support M1-powered Macs natively. 

Amazon first [launched](https://www.zdnet.com/article/aws-offers-mac-ec2-instances-here-what-it-means-for-apple/) Mac EC2 instances during re:Invent 2020\. EC2 Mac instances are dedicated Mac mini computers attached via Thunderbolt to the AWS Nitro System, making the Mac mini appear and behave like another EC2 instance. 

The new [EC2 M1 Mac instances](https://buy.geni.us/Proxy.ashx?TSID=368250&GR%5FURL=https%3A%2F%2Faws.amazon.com%2Fec2%2Finstance-types%2Fmac%2F%3Ftag%3Dzd-buy-button-20%26ascsubtag%3D%5F%5FCOM%5FCLICK%5FID%5F%5F%7Ca447c80a-2c07-4570-9cb0-2dbd8cedaec4%7Cdtp&dtb=1) specifically use a Mac mini featuring an M1 SOC with 8 CPU cores, 8 GPU cores, 16GiB of memory, and a 16 core Apple Neural Engine. The AWS Nitro System delivers up to 10Gbps of VPC network bandwidth and 8 Gbps of EBS storage bandwidth.

The new M1 instances deliver up to 60% better price performance over the x86-based EC2 Mac instances for iPhone and Mac app build workloads, AWS said.
